目标二　实验室中研究不同价态含硫物质的转化
1. 不同价态含硫物质的转化
在含硫化合物中，-2 价硫具有还原性，+4 价硫既有氧化性又有还原性，+6 价硫具有氧化性。不同价态之间的转化需要通过氧化还原反应实现。
预期的价态转化选择试剂实验操作和现象实验结论
-2 → 0H₂S、SO₂将 H₂S 通入 SO₂ 水溶液，出现淡黄色沉淀SO₂ 具有氧化性
0 → +4S、O₂硫在空气中燃烧，发出淡蓝色火焰S 被氧化
+4 → +6SO₂、氯水通入氯水后溶液褪色，滴加 BaCl₂ 生成白色沉淀SO₂ 具有还原性
+6 → +4浓硫酸、Cu加热，产生有刺激性气味的气体浓硫酸具有强氧化性
2. 相同价态含硫物质的转化
SO₂ + H₂O ⇌ H₂SO₃；SO₂ + 2NaOH = Na₂SO₃ + H₂O；Na₂SO₃ + H₂SO₄ = Na₂SO₄ + SO₂↑ + H₂O
归纳：同价态含硫物质之间的转化，一般通过酸碱反应实现，元素化合价不发生改变。

归纳总结
（1）含硫元素的化合价升高或降低时，一般需要加入氧化剂或还原剂，通过氧化还原反应实现。
（2）同一种元素相邻价态之间（如 S 与 SO₂）不发生氧化还原反应。
（3）含硫物质的连续氧化过程：H₂S → S → SO₂ → SO₃ → H₂SO₄。

课堂笔记
① SO₂ 与 CO₂ 的鉴别：分别通入品红溶液，褪色且加热后恢复红色的是 SO₂；也可通入酸性 KMnO₄ 溶液，紫红色褪去的是 SO₂。
② 除 CO₂ 中混有的 SO₂：将气体通入饱和 NaHCO₃ 溶液或酸性 KMnO₄ 溶液，不能用 Na₂CO₃ 溶液（会同时吸收 CO₂）。
③ 尾气处理：SO₂ 属于酸性氧化物，用 NaOH 溶液吸收，防止污染空气。
